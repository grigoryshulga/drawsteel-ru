Иногда герои находят руководства — особые книги, схемы, осведомленных НПС, сверхъестественные записи и т.д. — предоставляющие важную и легко понятную информацию, относящуюся к проекту отдыха. Каждое руководство имеет значение знания и связь с конкретным проектом, что значительно сокращает время, необходимое для его завершения. Когда герой изучает руководство в качестве деятельности отдыха, он получает значение знания руководства в виде очков проекта для своего проекта. Руководство не может быть использовано повторно для конкретного экземпляра проекта, хотя его можно использовать для другого проекта того же типа.

Руководства выдаются по усмотрению ведущего, обычно как инструмент, позволяющий ускорить выполнение сложных проектов для кампаний с небольшим количеством отдыха. Например, проект отдыха «Построить дирижабль» имеет цель проекта 3000, что требует немалого количества времени на отдых. Но если герой находит руководство, описывающее, как создать дирижабль, и дающее ему 1000 и более очков проекта для этого проекта, время создания может быть значительно сокращено.

Руководство должно предоставлять информацию на понятном вам языке, чтобы вы получили от него полную пользу. Если руководство использует язык, родственный тому, который вы знаете, вы получаете только половину значения знания руководства (округленную вниз) в виде очков проекта для вашего проекта.
